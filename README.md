# 3GPP Codebook Simulation

This repository provides a simple Python script for simulating 3GPP Type-I and Type-II codebooks. It also demonstrates PMI (Precoding Matrix Indicator) selection and generates beam pattern figures.

## Usage

Run the following command to execute a basic example:

```bash
python codebook_sim.py
```

The script prints the selected PMI index for a sample channel and saves a beam pattern figure to the current directory.
